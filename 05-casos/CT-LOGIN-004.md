# CT-LOGIN-004: login com senha errada

- **Pré-condição:** página de entrada da loja de treino aberta.
- **Dados de teste:** usuário standard_user, senha inventada senha123.
- **Passos:**
  1. Digitar standard_user no campo "Username".
  2. Digitar senha123 no campo "Password".
  3. Clicar em "Login".
- **Resultado esperado (escrito antes):** a mensagem "Epic sadface: Username and password do not match any user in this service" e a página continua na entrada.
