# Ferramentas do projeto

| Ferramenta | Para quê |
|---|---|
| Chrome e Dev Tools | testar a loja de treino, ver o Console e a Rede |
| VS Code | escrever casos, bugs e relatórios em Markdown |
| Git e GitHub | guardar o portfólio e mostrar o histórico |
| Postman | testar as APIs de treino (Restful Booker e Petstore) |
| Node.js e Playwright | testes automáticos da tela |
| k6 | plano e leitura de carga leve |

Sites de treino usados: a loja de treino (saucedemo.com), Restful Booker, Swagger Petstore e The Internet.
